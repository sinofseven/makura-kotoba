# サブコマンド実装の基本骨組み

## 目的
サブコマンド実装のための雛型を作ってほしい。

## 要望
サブコマンドを実装してください。各サブコマンドの処理は `println!()`だけにしてください。

## プラン
clap クレート（derive feature）を使用してコマンドライン引数をパースし、`apply` と `init` のサブコマンドを実装する。各サブコマンドの処理は `println!()` で出力のみを行う。
